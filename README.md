# Grimpe EPS

Appli hors ligne de suivi d'escalade pour les cours d'EPS : import Excel des classes et des voies (couleur, cotation, secteur, hauteur), passages en séance (moulinette / tête, enchaînée / repos / non finie, assureur), permis grimper / assurer / tête, carnet de voies, classement et export Excel.

Site statique : `index.html` + `manifest.json` + `sw.js` (fonctionne hors connexion après la première visite, installable sur l'écran d'accueil).
