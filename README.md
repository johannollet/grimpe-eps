# Grimpe EPS

Appli de suivi d'escalade pour les cours d'EPS : import Excel des classes et des voies (couleur, cotation, corde), plan du mur, passages en séance, roulette, meilleurs grimpeurs, classement.

- `public/` : l'appli (fonctionne hors ligne, installable sur l'écran d'accueil).
- `netlify/functions/sync.mjs` : synchronisation des tablettes et code d'accès (Netlify Blobs). Code par défaut : 2335, modifiable dans l'onglet Données.
